## 用户界面

1. 比赛载入后，标题栏的 **✦ AI 复盘** 展示已有报告。第一次没有报告时显示“尚无复盘”；没有模型密钥时只允许阅读。
2. 总结先于动作点评：本局标题、概述、值得保留的操作、改进重点与局限。
3. 当前对局进度条上覆盖非侵入式标记；按 **critical 红、major 橙、tip 蓝、positive 绿** 区分。一个标记包括文本标签/符号，近距离合并成计数，点击跳转到记录的动作与 **确实可用的动作前/后局面**。
4. 可拖动、可收起的半透明窗口；卡牌名称（存在于局面内并校验过的）保持英文；中文解释，置信度和证据局限分别展示。
5. 不篡改已有 `GameBoard`、`ReplayControls`、`TurnSlider`、`replayStore`、`coach_notes`、Live Coach API 或比赛 JSON。原有“重建说明”和“下载 Coach Context”继续保留。

## 数据流与安全边界

- `GET /api/matches/:id/review?game=N`: `status: missing | stale | ready`；使用独立 SQLite `reviews.sqlite3`，不触碰历史档案。
- `POST /api/matches/:id/review/generate?game=N`：**必须用户主动点击**、loopback 同源 Origin、非简单自定义请求头、空请求体。缓存有效则直接返回；同时仅允许一个新任务；没有独立密钥返回 501，不做任何自动付费请求。
- 生成器仅使用每个已记录的 **before** 快照（没有 before 的决策不评论），每个行动单独询问模型以防止未来信息流入早期评价。其后用整局事件时间线与此前建议生成总结。
- 每局最多分析 8 个已记录的玩家行动 + 1 个总结调用（正常情况下最多 9 次模型请求，实际候选不足则更少；失败节点不重试，也不根据失败结果造建议）。限制写入总结以免误认为整局每一步已被检查。
- 模型不得看到完整原始日志、对方未公开手牌、未来抽牌或自动推断的合法行动列表。英文卡名标签只从该节点玩家已可见的牌区中提取。
- 每份报告包括回放状态哈希、动作锚点、严重度、置信度及边界。重新导入改变已记录状态会返回 `stale`，不把旧建议强行映射到新节点。
- 单独的远程模型连接仍会发送选择的已脱敏决策快照、事件和摘要，用前应明确同意将这些信息发给提供方。

## 本机开启模型（仅明确同意 API 计费后）

当前一期只支持明确配置的 DeepSeek 非流式 JSON 接口，不继承已有语音教练的 API 许可，也**没有**自动切换其他提供方。

在实际启动 Replay 服务的终端/进程环境中设置：

```sh
export MTGA_REVIEW_DEEPSEEK_API_KEY='<用户自行配置的独立密钥>'
# 可选，默认 deepseek-chat
export MTGA_REVIEW_DEEPSEEK_MODEL='deepseek-chat'
```

**不要把密钥提交 GitHub 或嵌入浏览器代码。** 实例必须由本机 Node 服务读取环境变量。没有密钥时 UI 仍可显示以前保存的 AI 复盘；若没有缓存，则展示“尚未配置”。这不影响现有语音教练或 MTGA 对局数据同步。

## 复现与验收

可运行的离线后端测试（需 Node 24 与本仓库根目录依赖）：

```sh
node --test tests/replay-review.test.mjs tests/replay-review-http.test.mjs
npm test
```

所有模型输入由合成局面和模拟响应构造，**不调用真实收费 API**。

全量 Viewer 验收必须回到原 Mac 工作区：
- 遵守 `docs/DEVELOPMENT.md` 的上游许可证、素材补全及不发布限制。不得把缺失的 19 个文件上传仓库，或提交含上游源码的补丁。
- 测试 `npm run viewer:test:full` 与 `npm run viewer:build`；手动打开本地 Viewer。
- 验收最新真实 Quick Draft 回放和至少一局有重复 GRE frame、缺失 before-state 的回放；核对进度条彩点与锚点一致、点击是该动作之前的真实局面、移动浮窗不遮挡牌。
- 切换比赛、切换局数、更新归档、拖动时间轴、播放到结尾，确保旧报告正确失效，不显示别局建议。
- 校验未配置密钥、模型失败、网络中断、没有值得点评的行动时回放仍正常。
- **需要明确授权后**才做一局真实 API 的小规模成本/延迟/正确性测试。

## 已知限制与后续

1. 本期 AI 并非全动作搜索，不会计算准确的优劣胜率、所有法术力/优先权、所有合法打法；建议不是规则引擎判决。
2. 当前是页面内浮窗，非 macOS 独立置顶游戏浮窗；服务端推送和语音教练照旧。
3. 为避免改动上游许可不明的 `TurnSlider.tsx`，彩点以独立 overlay 附着现有 range 控件，Mac 实机必须验证位置及缩放表现。
4. 仍未增加 Draft 选牌 Replay：保留为二期，需检验每抓候选牌是否完整、有无下一抓信息倒灌。
5. 旧“教练笔记”继续显示手工/导入笔记，AI 复盘存储于独立 sidecar，不冒充已自动生成的旧笔记。
