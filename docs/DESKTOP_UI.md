# 桌面界面范围

2026-10-31。Replay 统一维护桌面界面。工作区最小宽度为 1200px，
较窄的电脑窗口允许横向滚动，不切换为手机排列。

移除全站按窄屏宽度切换的布局，包括顶部工具栏、比赛列表、战场、
播放控制、教练面板、复盘浮窗、轮抽记录与构筑对比。
轮抽仅保留左侧记录列表和右侧切手控制；删除手机下拉框、
底部切手栏、安全区留白和评论浮窗为底栏预留的 80px。
构筑对比保持两列。

保留电脑窗口高度压缩时的滚动控制、弹窗边界限制、键盘操作和减少动态效果设置。
这些服务于桌面窗口操作，不是额外的手机布局。没有新增依赖、请求或后台任务。

空格键统一打开／收起当前页面的AI复盘（比赛、轮抽和构筑对比页）。
沿用顶部复盘按钮的开关行为，展开时恢复正文；长按只切换一次并阻止页面滚动。
在输入框、下拉框、可编辑内容、输入法组合输入及原生弹窗内不触发，
带修饰键的空格也不触发。空格不再播放／暂停，播放控制保留按钮操作。
构建及17项复盘／选牌相关测试通过；独立Chrome验证回放、分析、选牌和构筑对比页开关、
按钮聚焦时不连带切手、长按防重复、输入框／可编辑内容／卡牌弹窗隔离，
以及已折叠复盘重新打开时恢复正文。前端错误和后台写请求均为0。

## 卡牌边缘

上一版给每张牌持续施加透视旋转，叠加浅色硬边、内侧高光和较大模糊阴影。
这些效果是本次排查边缘发虚的主要嫌疑；没有取得可逐像素审阅的截图证据。
本轮去掉常驻透视、旋转、缩放和高光覆盖层，只保留两条暗色薄边与短接触阴影。
悬停上移 3px，不改变牌的布局尺寸或叠放顺序，插画仍可见。
键盘聚焦时可将当前牌提到前方，便于完整看清焦点；减少动态效果时禁用位移。

只参考以下项目的行为设计，未复制第三方实现或引入库：

- [Draftmancer Card.vue](https://github.com/Senryoku/Draftmancer/blob/master/client/src/components/Card.vue)：
  普通牌与闪卡效果分开，透视和反光由 `.foil` 分支控制，
  退出时将旋转归零；不是给全部普通牌持续施加倾斜。
- [vanilla-tilt 官方选项](https://github.com/micku7zu/vanilla-tilt.js#options)：
  默认起始角度为零、缩放为 1、反光关闭。这里采用“静止时保持原始牌面”的思路，
  不接入其鼠标跟随、陀螺仪或额外脚本。

- 全部 16 处按窄屏宽度切换的媒体规则已移除；源码中不再有手机专用选择框、
  安全区样式或按窗口宽度切换的布局逻辑。
- `npm run viewer:build` 与 `npm run viewer:test` 通过，156 项既有测试全部通过。
- 独立 Chrome 检查 1200×800、1280×800、1440×900、1920×1080：
  无页面横向溢出，切手控制固定在右侧，构筑对比左右并排；
  1000px 宽电脑窗口保持 1200px 工作区并允许滚动。
- 真实记录中的首尾切手、41／42 张已选牌边界、侧栏收放、点击／键盘放大、
  Escape、回放步进、分析侧栏、比赛列表和评论浮窗移动通过。
- 卡牌静止时计算变换为 `none`，没有高光伪元素；悬停只上移 3px，
  不改变相邻牌的位置，下一张插画仍可点击。悬停新增卡图请求为 0；
  减少动态效果设置下无位移。
- 合成布局页验证矮电脑窗口滚动按钮、12 张堆叠和分析侧栏同时存在时可操作。
  合成数据只用于布局页，不写入真实记录。
- 浏览器运行错误为 0，测试中没有请求后台写操作；`git diff --check` 通过。
