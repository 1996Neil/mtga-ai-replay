# 对战复盘围绕攻防计划，只标记必要决策

完整方法、原始资料与多回合因果分析见[复盘方法](GAME_REVIEW_METHOD.md)。先确定当时的赢法和谁更适合拖长，再追查资源用途与后续分支，不只收集确定的单手错误。

编写前执行[离线决策检查](GAME_REVIEW_AUDIT.md)。先按真实来源逐回合完成选择比较，再决定哪些展示。拿牌不只比较对手牌面强弱，还要核对双方实际色源、落地后费用、借牌门槛，以及本轮能否兑现；结算后的回收、聚能、新对象和备妥也要计入同一轮。界面与来源校验通过，只说明内容能正确绑定和展示。

先阅读整盘每个回合的手牌、法术力、场面、战斗和堆叠，再挑选有决策价值的位置展示。评论数量由内容决定。普通按曲线下怪、正常环流找地和重复的资源提醒，不单独制造标记。

不按比赛平均分配点评。焦灼局要追查连续几轮的计划，以及补资源、留互动、交换身体与转守为攻之间的取舍；多个有独立后果的决策分别评论。同一种错误的重复出现可合并，不能把“突出重点”简化成每局只挑一处。短局和分支较少的比赛可以只有总结。

评论应给出明确选择，说明收益与代价。计算真实费用、颜色、加税、指示物、临时效果和对手已公开的回应；配合必须有当时可用的牌与施放窗口。评价阻挡时，既算本轮承伤，也算失去哪些身体、下一轮如何反攻或返场。保留身体吃伤害可能是正确的获胜路线。

总结交代整盘主线与主要转折，逐条评论补充具体计算。关键未知只放在它实际影响的判断旁边。浮窗直接呈现局面、选择和理由，去掉重复置信度、规则裁定说明、观察／建议／原因标签、分析边界和底部免责语。评论颜色、导航、开合和同步行为保持原有流程；没有标记的比赛仍可阅读总结。
