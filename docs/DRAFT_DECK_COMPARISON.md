# 轮抽结束后的构筑对比

实现模式。先用当前最近的完整 FRA 轮抽做样板：推荐40张、MTGA式按类型分行／费用分列的卡组、实际使用版本及增减比较。只为这一场编写推荐，不批量生成其他轮抽的内容。

选牌过程与构筑对比是同场的两个页签。选择结束后可进入构筑页；按用户要求只以电脑使用为目标，推荐和实际牌表并排展示，较小电脑窗口保留桌面工作区并允许滚动。只分生物（含神器生物）与其他两行，地也归入其他；同一行费用从左向右，数量合并。同费用的牌保留标题、插画与类别栏，下一张只覆盖下方文字框。点击卡牌沿用现有预览。

左右牌表共用费用列和各类的最大叠牌高度，框头、费用栏、生物行与其他行对齐。“你的卡组”移入框头，增减说明放在牌表下方。推荐下方另外展示相对你的版本1建议移出的卡图，按真实移出数量标记−1、−2等；主牌上的增减标记移到顶部，叠放后仍可见。移出区的数量仅为建议删去的张数，例如7沼泽改6沼泽显示−1和×1。

构筑对比的推荐、实战与建议移出卡图统一使用选牌过程的暗色薄边、短接触阴影，
静止时保持正面原图，悬停仅上移3px；不添加亮边、反光或透视旋转。
卡牌容器允许阴影和抬起效果显示，叠放次序不因悬停变化，保留下一张插画；
加入／移出仍通过顶部数量标记区分。键盘聚焦时将当前牌提到前方，减少动态效果时关闭位移。

实际版本来自已经关联、且属于当前账号的对战归档主牌组。按对战时间排序，只有相邻牌表相同才合并；A→B→A保留三个使用阶段。地牌美术或导出顺序变化不单独制造版本。没有观测到的编辑不推断为历史。每个版本展示使用场次、战绩、相对上版改动与相对推荐增减，所有观测版本都保留。

新增只读 `GET /api/draft-runs/<run_id>/decks?account=<account_key>`。推荐文件位于数据目录的 `draft-decks/<account_key>/<run_id>.json`，只接受固定身份、来源指纹、40张主牌、完整牌池张数及已识别基本地。目录／文件不接受符号链接，输入大小有上限。后台验证来源，不把技术说明加入教练正文。

只读提取归档deck字段和已有卡牌资料，不重建回放、不扫描日志、不下载卡图以外的新依赖、不请求付费模型。新功能不修改游戏内卡组或比赛数据库。推荐保留原始完整池，无法绑定或账号冲突时不展示别的账号牌组。

验收重点：40张计数、备选来自完整池、类型与费用排序、重复数量、相邻版本合并与改回、基本地印刷差异、各版本增减、账号与过期源隔离、切换轮抽不串数据、保留评论窗交互。只跑相关测试、类型／构建及浏览器检查。
