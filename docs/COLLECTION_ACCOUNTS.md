# 收藏按游戏账号保存

模式：实现；同时调查牌图失败与旧选牌的时间，不改写旧数据归属。

目标：Replay 中选择的游戏账号决定收藏状态、保存位置和上传路径；切换账号不继承
另一账号的收藏任务结果或资源数量。桌面命令更新时明确确认当前账号。

约束：保留原 `collection/latest` 与本地未分类快照，不自动迁移、复制归属或删除。
只使用既有哈希账号键，原始 ID、账号昵称、日志和机器路径不进入上传。
不新增依赖，不进行本次真实收藏读取或上传，不改动其他正在进行的同步开发。

完成条件：两个账号独立保存、比较、读取与上传；更新 A 不覆盖 B 或旧快照；
缺少账号、确认失败、读取前后账号变化均不更新；共享锁防止并行读取；
API、CLI、网页和上传校验使用相同的账号键；相关回归及独立审查通过。

风险与边界：当前收藏读取 helper 只读取卡牌和资源，不能自动证明游戏账号。
用户必须确认 Arena 当前登录与所选账号一致，并核对采集器的活动账号在读取前后未改变。
无法确认归属的旧收藏继续留在原位置。

## 实现

- 本地快照存放在 `collection/accounts/<account_key>/`，每个账号独立指针、版本、卡牌缓存与检查记录。
  旧的 `collection/current.json` 保留为未分类收藏，不能自动视为当前账号的收藏。
- 新快照的摘要带 `account_key`，整体内容哈希也包含账号键。读取、保存和上传均检查账号与目标位置一致。
- 远端使用 `collection/accounts/<account_key>/latest/` 与对应账号的 README；
  原 `collection/latest/` 不覆盖。每个账号有独立上传状态。账号键可由既有轮抽／比赛记录对应，
  不上传名字或原始 Arena ID。
- 上传、删除多余分片、提交与远端字节回读只检查当前账号的路径。A 上传失败留下的提交，
  B 不能顺带推送；先完成 A 的重试。
- 使用原来的全局收藏操作锁，避免两个账号同时读取游戏；任务完成记录按账号独立，
  服务重启会检查所有账号的未完成任务。
- 网页的状态、更新和重试上传请求带所选账号；确认文字显示账号名。未分类视图不能更新。
  读取前后核对本机采集器活动账号；不同或缺失时阻止保存。
- 命令默认选择采集器活动账号，显示名称并要求确认；可用 `--account <账号键>` 指定。
  `status --legacy` 只读查看旧收藏。真实账号身份仍依赖用户确认，采集器记录只是补充核对，
  不能证明读取过程中没有切换后再切回。

  失败提交归属限制、共享同步锁、外部改动拒绝及远端字节验证。
- 36 项账号隔离、轮抽备份、牌图及上传内容／历史校验通过。
- Viewer 生产构建通过；包含新增账号请求范围检查在内的 140 项前端测试全部通过。
- 独立浏览器用隔离响应验证：每次请求携带账号、确认文字对应账号、
  切换账号清除原结果、未知账号禁用更新。所有 POST 均拦截在测试响应中，
  没有向真实收藏接口发送更新／上传。
- 独立审查未发现阻塞问题；审查者独立执行 32 项收藏／任务测试和
  2 项本地 bare Git 多账号上传测试，全部通过。
- 空闲时通过已有启动器正常重启本地 Replay，新接口已生效。
  重启前后旧收藏指针的 SHA256 相同；两个真实账号的收藏任务各自为空，
  没有把原未分类结果分配给它们。

本次没有实际读取 Arena 收藏或向用户远端上传收藏，因此不能声称已验证真实
helper 授权与真实远端写入。后续由用户确认账号后从界面或命令执行。
本次没有改写任何历史账号归属、迁移旧快照或提交／推送源代码。

## 牌图调查

在本地牌库可确定准确印次的情况下，一些较新的 Arena ID 尚未出现在牌图服务的编号映射中。
实测 `106413`（Codie, Ravenous Codex）、`106411`（Afterthought Sentry）、
`106521`（Tam, the Possibility）及 `106336`（Flourishing Grapple）：
Arena ID 查询返回 404，而 `FRA` 的收藏编号 168、166、276、102 英文印次查询返回 200。
因此仅清空图片缓存不能解决编号映射缺失。

当前集成代码已用本地系列／收藏编号查询准确印次，并校验语言、系列、编号和牌面；
允许公共服务缺少 Arena ID，但拒绝明确冲突的 Arena ID。缓存旧图也须符合本地印次身份。
牌图修复由同一工作区内的并行任务提供，本次未覆盖其修改；本次已执行集成测试和真实接口核验。
重启后上述四张的资料身份均 verified、图片 HTTP 200，继续缓存至本机。
