# 什么才是好的万智牌复盘

先确定这盘怎样才能赢，再沿关键分支追查资源、时钟和后续选择怎样变化，最后把分析变成下一盘能用的判断。这是本文综合资料与实际回放后采用的方法，不是任何一篇文章的原话。

阅读顺序：先解释整盘计划与连续决策，再用590这盘说明怎样追查转折，最后说明评论筛选与下一盘的练习方法。

## 复盘要解释计划如何成立、改变或失效

Reid Duke在《Becoming a Better Player》中从“为什么获胜者会赢”追问操作、判断、读牌、构筑与运气，并强调研究应服务自己的练习。他在《Role Assignment》和《Inevitability》进一步区分：谁需要主动进攻，谁有能力拖长，以及这些角色如何随比赛变化。只有生命领先，未必拥有拖长后的优势。[1][2][3]

因此复盘的第一句话不应是“这里应不应该挡”，而应先回答：**根据当时信息，我靠什么赢，时间更有利于谁？**

“靠什么赢”要落到现有牌：是让某个飞兵再打两次，是用大狼逼双挡后穿过最后几点，是把坟场变成两个大身体，还是让对手耗尽可用资源。不能把“继续赚牌”“等炸弹”“把场面做好”当成已经说明了赢法。

计划也不意味着提前固定若干回合。新威胁出现、自己的主要身体被解、对方发动机建立，都会改变角色。好复盘要指出**何时应更新计划、更新后哪一种资源变得最紧缺**，而不是要求每一步继续服从开局的打算。

## 评价一个选择，要看到它如何限制后续选择

单步检查规则与费用是必要工作，但解释力不够。Duke在《Sequencing》中说明，行动先后会影响后续能做什么，也会改变对手作决定时知道的信息；他在《Tempo》中把节奏放进有限回合与资源兑换中讨论。[4][5]

我们据此按三个层次读回放：

| 层次 | 需要解释的问题 | 不足的评论 |
|---|---|---|
| 当前动作 | 目标、伤害、费用和规则是否算对？ | “挡了能少掉四血。” |
| 整个回合 | 身体、留费、攻击与忠诚安排能否共同完成目标？ | “先下这张也可以。” |
| 连续计划 | 这轮换到什么，放弃什么，下一轮还剩哪些能赢的分支？ | “后来这只怪死了，所以之前不该攻。” |

不强迫每条评论写三层，但整局复盘必须把相关层次连起来。一个动作可能本身正确，却是此前选择使它变成唯一保命线。不能把最后被迫承伤的位置，当作优势消失的起点。

追查时先找**还能主动选择的最早关键窗口**，并解释影响如何传递。也不是一律越早越对：必须有当时已知、可支付的替代方案，以及它改善后续的具体机制。

有些局从未建立优势，也有些局是多个小取舍共同缩窄分支。找到一个关键窗口，不等于找到唯一败因；找不到能翻盘的单一操作，也不表示整盘没有值得学习的决定。

例如590这盘的真实过程：

> 八费回收并重下唤师 → 得到四二与一次看手，却无费用使用现有互动 → 下一轮四二交换、大狼又遭死触伤害处理时，手中答案不能介入 → 剩下的一攻飞兵必须连续命中，互动开始只能购买生存回合。

这里可以批评的是**为了某种收益关闭了哪些应对分支**，不能声称八费用尽必然会抽到那张去除、也不能声称留费一定赢。替代方案“游魂、缺席清死触、留反召唤”来自当时已有手牌，目标是让主要时钟继续工作。它也付出暂缓看手与四二身体的代价。

## 用当时信息评判，用后来结果检验推理

Baron与Hershey的原始研究发现，知道好坏结果会影响人们对同一个决策的评价。这不等于结果没有信息价值，而是不能把结果直接当成当时选择质量的证明。[6]

复盘按时间推进时，把已见牌、已发生选择、合理推断和事后才知道的信息分开：

- 对手后来抽到某张牌，可以解释实际局面怎样发展，不能倒填成几轮前必知的手牌。
- 对手当前有死触、自己只有一个主要终端，已经足以讨论留费，不需要提前知道对手下一张会是伤害咒语。
- 看手、攻击和施法透露的新信息，应从它出现的时点开始进入后续判断。复盘不能始终停留在最初的信息。
- 对隐藏牌的考虑可以来自已知牌表、已展示的颜色、留费和此前行动，但须说明推断依据；没有数据就不编具体概率或胜率。

“输了”可以提出问题，却不能替我们回答问题。“没找到确定错误”也不表示没有重要取舍可讲。

## 比较的是能应变的方案，不是对手照剧本走的连招

Duke在《What Is Magic?》把万智牌的长期思考与不确定性放在一起：未来的牌和对手的资源并不全在眼前，因此要比较可能发生的情况。[7]

替代线至少要说明：

1. **怎样执行：**真实颜色、费用、目标和时机；必要时算到下一次攻防或资源兑现。
2. **对手怎样合理应对：**可以改阻挡、改攻击目标、重下被弹的牌，或把装备移到另一只生物。
3. **为什么仍倾向它：**它提高哪些资源的质量、缩短什么时钟，或保留哪些有用分支。
4. **代价：**放弃多少伤害、哪张手牌、什么未来答案，或者向对手开放什么机会。

推演长度随论点决定。若主张“下一轮能换掉两路”，就必须完成那次攻防计算；若主张“先争一个回合”，不要顺手把三轮后的胜利也当作已经证明。关键收益验证清楚后便停止延长，不靠虚构抽牌补齐胜利。

## “优势”必须具体，才知道它在哪里丢掉

以下是本项目使用的分析项目，不是把比赛压成一个伪精确分数：

- **有效场面：**身体能否攻击、阻挡或完成交换，而非只数数量与总攻防。
- **双方时钟：**要几次有效命中，需谁先交互动，攻击者是否还要回来防守。
- **可兑现资源：**手牌是否付得出；墓地和放逐牌是否仍有合法使用权；已有引擎还需要什么燃料。
- **当前费用：**总费用之外还有颜色、横置来源、下一轮要留的窗口。
- **拖长后的收益：**谁持续造兵、谁只是一换一，哪一边的新抽牌更容易变成有效行动。
- **选择余地：**一次全用费、一次弃地、一次交换后，是否只剩“必须连续抢血”或“必须抽到某类牌”这一条路。

尤其要避免把承伤自动记成损失：用生命保留能返场的身体，可能是在保住赢法；相反，为省两血交换掉唯一先攻生物，也可能让下一轮再没有可行防线。

## 展示重点由问题决定，不由错误数或比赛时长决定

实际执行要先完成[决策检查记录](GAME_REVIEW_AUDIT.md)，再筛选显示。清单从真实动作和状态产生；看手选择单独比较双方的支付能力、即时用途和留下另一张的后果。每回合的落地、施放、目标、能力与攻防都要留处理理由；没有点评的位置也不能只填一句“已看过”。清单缺项、来源改变或最终点评正文被改写，都要重新检查。

完整读比赛，再选有学习价值的分支展示。赢局也可能包含坏决策，输局也有值得保留的判断；长局不自动需要更多字，但角色多次变化、资源用途反复转换时，分析必须覆盖这些变化。

一次失误导致后面被迫垫挡，不要把每次垫挡都重复算作新错。两个决定即使相隔很近，若一个涉及法术力效率、另一个涉及资源目标，则可分别讲清。

每条正文尽量回答：**当时我更倾向什么；为什么；对手能怎样回应；我为此接受什么。** 可用“我更倾向”明确战略判断，不必等到证明唯一最优；这种表达后面必须有实质比较，不能用它代替判断。

整局总结按因果推进：原本的赢法 → 对手怎样改变局势 → 哪个窗口需要换计划 → 实际选择怎样收窄后续 → 下次如何识别。不能只把施法日志换成一段叙述。

## 一次复盘应留下能再次检验的问题

PVDDR关于职业队测试的文章强调，先明确需要解决什么信息，再安排针对性的测试；盲目多打并不自动形成可用结论。[8]

用于个人复盘时，结尾应留下少量可迁移的判断，例如：

- 已有主要终端时，我是否为了再次看手，把手里的互动变成不能施放的牌？
- 对方的长期资源更强时，我是否仍把忠诚优先用于抽牌，而不是现有的复制补场？
- 决定抢血前，我有没有算清必须买几个完整攻击回合，以及何时还能转回防守？

这些是从本批回放提出的练习问题，不是所有局面都必须遵守的口号。下一盘检查它们是否适用，才能验证复盘到底改进了什么。

接下来几盘遇到相似局面时，记录当时目标、费用安排、预期的下一轮与对手回应，把实际结果另记。先检查预判和执行是否得到改善，再积累多盘证据；不能因为下一盘赢了，就宣布这个方法已经验证成功。
